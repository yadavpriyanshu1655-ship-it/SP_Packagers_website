# SP Packagers — Packaging Business Website

## Included
- Responsive packaging-box storefront
- Product catalogue with search and category filters
- Pizza, food, courier, bakery and retail box products
- Shopping cart with quantity controls
- Checkout / order placement
- Customer + business details
- Delivery charge calculation
- Payment method selection
- Order IDs
- Persistent orders in `data/orders.json`
- Admin order-receiving dashboard
- Order status updates: New → Confirmed → Packed → Shipped → Delivered
- Bulk/custom quote enquiry UI
- Mobile responsive design
- LocalStorage cart
- Easy to edit product catalogue and business details

## Run in VS Code

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   `npm install`
5. Run:
   `npm start`
6. Open:
   `http://localhost:3000`

## Important
This is a working starter business website. For a real production business, connect:
- WhatsApp Business API or a WhatsApp order button
- Razorpay/Stripe payment gateway
- MySQL/PostgreSQL/MongoDB database
- Real authentication for admin
- Image uploads/product management
- GST invoice generation
- Email/SMS/WhatsApp order notifications
- Hosting/domain and HTTPS
